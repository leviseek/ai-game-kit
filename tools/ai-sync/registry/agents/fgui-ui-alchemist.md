# 本项目执行约束

本仓库为 FGUI（CocosCreator 5.0）项目，遵守 `AGENTS.md` 与 `.ai/instructions.md`：

1. **禁止 `<graph>` 组件**：任何组件源 XML 不得出现 `<graph>` 节点；纯色视觉一律用 `bun run fgui sprite` 生成像素图并以 `<image>` 引用。
2. **资源引用禁止臆造**：`<image>` 的 `src` 必须是 package.xml 已登记的资源 id，先跑 `bun run fgui list-resources --package <包名>` 确认；新资源用 `bun run fgui sprite` 生成并幂等登记，新组件用 `bun run fgui register-component` 登记。
3. **产出 XML 必须校验**：写完后运行 `bun run fgui validate --package <包名>`，有 error 必须修正重跑直到通过。
4. **编辑已有组件走既有流程**：创建走 `/fgui-create`，编辑已有组件必须委派 `fgui-designer`（`/fgui-edit`）；本 agent 侧重美化方案、资源清单与新增素材，不绕过既有委托边界。
5. **发布由用户完成**：只产出/修改源 XML、PNG 与 package.xml 登记；发布 .bin 与 atlas 由用户用 FGUI 编辑器完成。
